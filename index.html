探索日本優質旅宿

輸入地名或車站關鍵字（如：上野、京都、心齋橋），從建議清單中選擇地區，即可查詢該區域的即時空房。地區資料來自樂天旅行官方地區代碼，涵蓋範圍以樂天分區為準，非單一車站等級的精準定位。

進階篩選條件（選填）

以下條件會直接送給樂天旅行 API 做真正的篩選；星等門檻是查詢結果回來後，於瀏覽器端依平均星等再過濾（樂天公開 API 不支援用星等或「可免費取消」做查詢條件，取消政策目前無法比照樂天官網篩選）。

查詢結果

價格資料即時來自樂天旅行官方 API，僅供參考，實際金額與空房狀況以樂天／Booking.com 結帳頁面為準。 本工具不會抓取或顯示 Booking.com 的即時房價（避免違反其比價相關使用條款），「查看 Booking.com」按鈕僅導向其官網搜尋結果頁，由你自行比較。
